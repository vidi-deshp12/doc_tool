# rwmodel

This module defines the shared serialisation infrastructure for all domain models in the project [[target/app/models/domain/rwmodel.py]]. It imports `datetime` from the standard library alongside Pydantic's `BaseConfig` and `BaseModel`, and builds three closely related components on top of those primitives [[target/app/models/domain/rwmodel.py]].

The first is `convert_field_to_camel_case`, a utility function that transforms a snake\_case field name into camelCase by splitting on underscores, leaving the first word as-is, and capitalising the initial letter of every subsequent word before rejoining them [[target/app/models/domain/rwmodel.py::convert_field_to_camel_case]]. The second is `convert_datetime_to_realworld`, which accepts a `datetime.datetime` object, coerces its timezone info to UTC, renders it as an ISO 8601 string, and then replaces the trailing `+00:00` offset with a `Z` suffix to produce the compact timestamp format expected by the API [[target/app/models/domain/rwmodel.py::convert_datetime_to_realworld]].

Both functions feed directly into `RWModel`, the base Pydantic model that every domain model in the codebase inherits from [[target/app/models/domain/rwmodel.py::RWModel]]. `RWModel` extends `BaseModel` and carries an inner `Config` class derived from `BaseConfig` that wires the two functions into the model layer [[target/app/models/domain/rwmodel.py::RWModel]]. The `alias_generator` is set to `convert_field_to_camel_case`, so every snake\_case Python field automatically gains a camelCase alias for JSON serialisation without any per-field annotation [[target/app/models/domain/rwmodel.py]]. The `json_encoders` mapping delegates `datetime.datetime` serialisation to `convert_datetime_to_realworld`, ensuring consistent UTC timestamps whenever a model is dumped to JSON [[target/app/models/domain/rwmodel.py]]. Finally, `allow_population_by_field_name = True` allows model instances to be constructed using either the Python name or the generated camelCase alias, preventing breakage on the input side [[target/app/models/domain/rwmodel.py]]. `RWModel` itself declares no fields; its sole purpose is to propagate these three configuration choices uniformly to every subclass [[target/app/models/domain/rwmodel.py::RWModel]].

## RWModel

`RWModel` is a Pydantic model that serves as the shared base class for domain models in this codebase [[target/app/models/domain/rwmodel.py::RWModel]]. It inherits directly from `BaseModel` (Pydantic's root model type) [[target/app/models/domain/rwmodel.py::RWModel]], and its inner `Config` class extends `BaseConfig` to apply three project-wide serialisation settings [[target/app/models/domain/rwmodel.py]]. First, `allow_population_by_field_name = True` means instances can be constructed using either a field's declared Python name or its generated alias [[target/app/models/domain/rwmodel.py]]. Second, `json_encoders` maps `datetime.datetime` to a `convert_datetime_to_realworld` function, so any datetime field is serialised in the expected real-world format when the model is dumped to JSON [[target/app/models/domain/rwmodel.py]]. Third, `alias_generator = convert_field_to_camel_case` automatically derives a camelCase alias for every field, keeping the API's JSON representation in camelCase while the Python code uses snake_case [[target/app/models/domain/rwmodel.py]]. No additional fields are declared on `RWModel` itself; its value lies entirely in the configuration it passes down to every subclass [[target/app/models/domain/rwmodel.py::RWModel]].

## convert_datetime_to_realworld

Accepts a `datetime.datetime` object and returns a UTC-normalised ISO 8601 string with the timezone offset replaced by the trailing `Z` suffix [[target/app/models/domain/rwmodel.py::convert_datetime_to_realworld]]. It forces the datetime's `tzinfo` to `UTC`, formats it as an ISO string, then substitutes the `+00:00` offset with `Z` to produce the "realworld" timestamp format [[target/app/models/domain/rwmodel.py::convert_datetime_to_realworld]].

## convert_field_to_camel_case

Converts a snake\_case string to camelCase by splitting on underscores, keeping the first word unchanged, and capitalising the first letter of every subsequent word before joining them back together [[target/app/models/domain/rwmodel.py::convert_field_to_camel_case]].
