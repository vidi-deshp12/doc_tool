# rwmodel

[`rwmodel.py`](target/app/models/domain/rwmodel.py) is a small shared module that defines the base Pydantic model and the two helper functions that configure it [[target/app/models/domain/rwmodel.py]].

`convert_datetime_to_realworld` takes a `datetime.datetime` value, pins it to UTC, and returns an ISO 8601 string with the `+00:00` offset replaced by the compact `Z` suffix, producing the timestamp format expected by most web APIs [[target/app/models/domain/rwmodel.py::convert_datetime_to_realworld]]. `convert_field_to_camel_case` takes a snake_case string, keeps the first word lowercase, capitalises the first letter of every subsequent word, and joins them without a separator — converting, for example, `tag_list` to `tagList` [[target/app/models/domain/rwmodel.py::convert_field_to_camel_case]].

Both functions feed directly into `RWModel`, the base class that all domain models in this codebase extend [[target/app/models/domain/rwmodel.py::RWModel]]. `RWModel` inherits from Pydantic's `BaseModel` and bundles a nested `Config` that applies three settings to every subclass: `allow_population_by_field_name = True` so that fields can be set using their Python names as well as their aliases; `json_encoders` wired to `convert_datetime_to_realworld` so that `datetime.datetime` values are automatically serialised to the `Z`-suffixed format; and `alias_generator` set to `convert_field_to_camel_case` so that every field is exposed under a camelCase alias without any per-field declaration [[target/app/models/domain/rwmodel.py::RWModel]]. Because the alias generator runs automatically across all fields, any field that requires a *different* alias — such as one that maps to `tagList` from an external API contract — must declare it explicitly with `Field(..., alias="...")` to override the automatic conversion [[target/app/models/domain/rwmodel.py::RWModel]].

## RWModel

`RWModel` is a Pydantic model that serves as the shared base class for domain models in this codebase [[target/app/models/domain/rwmodel.py::RWModel]]. It inherits from Pydantic's `BaseModel` and applies a shared `Config` that governs how all subclasses serialize and deserialize data [[target/app/models/domain/rwmodel.py::RWModel]]. Three configuration options are set: `allow_population_by_field_name = True`, which allows fields to be populated using their Python names in addition to any assigned alias; `json_encoders` mapping `datetime.datetime` to a `convert_datetime_to_realworld` function, which controls how datetime values are serialized to JSON; and `alias_generator = convert_field_to_camel_case`, which automatically generates camelCase aliases for all fields [[target/app/models/domain/rwmodel.py::RWModel]]. Because `alias_generator` is active on every subclass, any field that requires a *different* alias must declare it explicitly via `Field(..., alias="...")` to override the automatic conversion [[target/app/models/domain/rwmodel.py::RWModel]].

## convert_datetime_to_realworld

`convert_datetime_to_realworld` takes a single argument `dt` of type `datetime.datetime` and returns a `str` [[target/app/models/domain/rwmodel.py::convert_datetime_to_realworld]]. It normalises the datetime to UTC by attaching the `UTC` timezone, converts it to an ISO 8601 string via `.isoformat()`, and then replaces the trailing `+00:00` offset with the compact `Z` suffix, producing a format commonly expected by web APIs [[target/app/models/domain/rwmodel.py::convert_datetime_to_realworld]].

## convert_field_to_camel_case

`convert_field_to_camel_case` takes a single string argument, `string`, and returns a new `str` [[target/app/models/domain/rwmodel.py::convert_field_to_camel_case]]. Its purpose is to convert a snake_case identifier into its lowerCamelCase equivalent [[target/app/models/domain/rwmodel.py::convert_field_to_camel_case]]. It does this by splitting the input on underscores, keeping the first word unchanged, and capitalising the first letter of every subsequent word before joining them all back together with no separator [[target/app/models/domain/rwmodel.py::convert_field_to_camel_case]]. For example, `tag_list` would become `tagList` [[target/app/models/domain/rwmodel.py::convert_field_to_camel_case]]. The function is defined at the module level in [`rwmodel.py`](target/app/models/domain/rwmodel.py) and carries no decorators [[target/app/models/domain/rwmodel.py]].
