# rwschema

This module serves as the schema foundation layer for ORM-compatible Pydantic models in the application [[target/app/models/schemas/rwschema.py]]. It imports `RWModel` from the domain layer and defines a single class, `RWSchema`, which extends it [[target/app/models/schemas/rwschema.py::RWSchema]]. The sole purpose of `RWSchema` is to enable `orm_mode = True` through a nested `Config` class that inherits from `RWModel.Config`, allowing Pydantic to populate model instances directly from ORM objects such as database rows, rather than only from plain dictionaries [[target/app/models/schemas/rwschema.py::RWSchema]]. No new fields are introduced at this level; the full field set is inherited entirely from `RWModel` [[target/app/models/schemas/rwschema.py::RWSchema]]. Any schema class in the application that needs to be constructed from database query results should inherit from `RWSchema` rather than `RWModel` directly, making this module the thin but essential bridge between the domain model layer and persistence-aware schema classes [[target/app/models/schemas/rwschema.py::RWSchema]].

## RWSchema

`RWSchema` is a Pydantic model defined in [`target/app/models/schemas/rwschema.py`](target/app/models/schemas/rwschema.py) that extends `RWModel` [[target/app/models/schemas/rwschema.py::RWSchema]]. It inherits all fields and configuration from its base class [[target/app/models/domain/rwmodel.py::RWModel]], and adds a single configuration change: it enables `orm_mode = True` via a nested `Config` class that itself extends `RWModel.Config` [[target/app/models/schemas/rwschema.py::RWSchema]]. This setting allows Pydantic to read data from ORM objects (such as SQLAlchemy model instances) in addition to plain dictionaries, making `RWSchema` the appropriate base for any schema class that needs to be populated directly from database rows [[target/app/models/schemas/rwschema.py::RWSchema]]. No additional fields are declared on `RWSchema` itself; its full field set is determined entirely by `RWModel` [[target/app/models/domain/rwmodel.py::RWModel]].
