# rwschema

This module defines the `RWSchema` class, which serves as the shared base for all request/response schema classes in the application [[target/app/models/schemas/rwschema.py]]. `RWSchema` extends `RWModel` and inherits all of its fields, field aliases, and base configuration [[target/app/models/schemas/rwschema.py::RWSchema]]. Its sole addition over the parent is a nested `Config` class that sets `orm_mode = True`, which allows Pydantic to populate model instances directly from ORM objects such as SQLAlchemy rows, rather than requiring plain dictionaries [[target/app/models/schemas/rwschema.py::RWSchema]]. Any schema class that needs both the common behaviour provided by `RWModel` and the ability to read data from ORM results can inherit from `RWSchema` to gain both capabilities at once [[target/app/models/schemas/rwschema.py::RWSchema]].

## RWSchema

`RWSchema` is a Pydantic model [[target/app/models/schemas/rwschema.py::RWSchema]] that extends `RWModel` [[target/app/models/domain/rwmodel.py::RWModel]], inheriting all of its fields and configuration. It lives in [`target/app/models/schemas/rwschema.py`](target/app/models/schemas/rwschema.py) and its sole addition over its parent is a nested `Config` class that enables `orm_mode = True` [[target/app/models/schemas/rwschema.py::RWSchema]], allowing Pydantic to read data directly from ORM objects (such as SQLAlchemy model instances) rather than requiring plain dictionaries. Because it inherits from `RWModel` [[target/app/models/domain/rwmodel.py::RWModel]], it also picks up whatever base configuration and field aliases `RWModel` defines. In short, `RWSchema` acts as the shared base for all request/response schema classes that need both the common model behaviour of `RWModel` and the ability to be populated from ORM rows [[target/app/models/schemas/rwschema.py::RWSchema]] [[target/app/models/domain/rwmodel.py::RWModel]].
