# __init__

The [`target/app/models/__init__.py`](target/app/models/__init__.py) file is an empty or near-empty package initialiser that marks the `models` directory as a Python package [[target/app/models/__init__.py]]. It contains no definitions of its own, serving purely as a namespace boundary so that the individual model modules within the package can be imported by other parts of the application [[target/app/models/__init__.py]].
