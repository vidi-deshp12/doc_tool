# logging

[`target/app/core/logging.py`](target/app/core/logging.py) is a small bridging module whose sole purpose is to connect Python's built-in `logging` infrastructure to the Loguru library [[target/app/core/logging.py]]. It imports the standard `logging` module alongside Loguru's `logger` object, and defines a single class to perform that connection [[target/app/core/logging.py]].

`InterceptHandler` is a custom `logging.Handler` subclass that acts as the bridge between the two systems [[target/app/core/logging.py::InterceptHandler]]. It declares no fields of its own beyond what it inherits from the standard handler base class [[target/app/core/logging.py::InterceptHandler]]. All of its logic lives in a single `emit` method, which receives a standard `logging.LogRecord` and translates it into a Loguru log call [[target/app/core/logging.py::InterceptHandler]].

The translation process has three steps. First, `emit` resolves the correct Loguru level name from `record.levelname`, falling back to the record's numeric level string if no matching named Loguru level exists [[target/app/core/logging.py::InterceptHandler]]. Second, to ensure Loguru attributes the log entry to the correct call site rather than to an internal frame inside the `logging` module, it walks the call stack upward from `logging.currentframe()`, incrementing a depth counter for every frame that still belongs to the standard `logging` machinery [[target/app/core/logging.py::InterceptHandler]]. Third, it calls `logger.opt` with the computed depth and the record's `exc_info` so that any exception context is preserved, then forwards the resolved level and the record's formatted message through that opt-configured logger [[target/app/core/logging.py::InterceptHandler]].

## InterceptHandler

`InterceptHandler` is a custom logging handler that extends the standard `logging.Handler` base class [[target/app/core/logging.py::InterceptHandler]]. It is not a Pydantic model and declares no fields of its own [[target/app/core/logging.py::InterceptHandler]]. Its sole responsibility is to act as a bridge between Python's built-in `logging` infrastructure and the Loguru logging library, routing any record emitted through the standard `logging` system into Loguru [[target/app/core/logging.py::InterceptHandler::emit]].

This bridging is performed entirely by its `emit` method, which accepts a standard `logging.LogRecord` and first resolves the corresponding Loguru level name from `record.levelname`, falling back to the numeric level string when no named Loguru level matches [[target/app/core/logging.py::InterceptHandler::emit]]. To ensure that Loguru reports the correct call site rather than an internal frame inside the `logging` module, `emit` walks the call stack upward from `logging.currentframe()`, incrementing a `depth` counter for every frame that still belongs to the standard `logging` machinery [[target/app/core/logging.py::InterceptHandler::emit]]. Finally, it invokes `logger.opt` with the computed `depth` and `record.exc_info` so that exception context is preserved, and forwards the resolved level together with the record's formatted message string through `logger.opt(depth=depth, exception=record.exc_info).log` [[target/app/core/logging.py::InterceptHandler::emit]].

### emit

Translates a standard `logging.LogRecord` into a Loguru log entry by first resolving the Loguru level name from `record.levelname`, falling back to the numeric level string if no matching Loguru level exists [[target/app/core/logging.py::InterceptHandler::emit]]. It then walks the call stack from `logging.currentframe()` upward, incrementing `depth` for each frame still inside the standard `logging` module, so that Loguru attributes the message to the true call site rather than the logging machinery [[target/app/core/logging.py::InterceptHandler::emit]]. Finally it calls `logger.opt` with the computed `depth` and `record.exc_info` to preserve exception context, then forwards the resolved level and the record's formatted message string via `logger.opt(depth=depth, exception=record.exc_info).log` [[target/app/core/logging.py::InterceptHandler::emit]].
