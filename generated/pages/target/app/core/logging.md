# logging

This module serves as a bridge between Python's standard `logging` module and the Loguru library, allowing application code to use the familiar `logging` API while delegating actual log output to Loguru [[target/app/core/logging.py]]. It defines a single class, [`InterceptHandler`](target/app/core/logging.py::InterceptHandler), which is the sole component in the file [[target/app/core/logging.py::InterceptHandler]].

[`InterceptHandler`](target/app/core/logging.py::InterceptHandler) inherits directly from `logging.Handler` — the standard library base class for all log record handlers — and adds no new fields of its own, making it a minimal, focused adapter [[target/app/core/logging.py::InterceptHandler]]. It is not a Pydantic model [[target/app/core/logging.py::InterceptHandler]]. The entire behaviour it contributes beyond its parent class is expressed through a single method, [`emit`](target/app/core/logging.py::InterceptHandler), which accepts a `logging.LogRecord` and returns `None` [[target/app/core/logging.py::InterceptHandler]].

When a log record arrives, `emit` first attempts to resolve the record's level name to a Loguru-native level; if Loguru does not recognise the name and raises a `ValueError`, it falls back to the raw numeric level as a string, ensuring that non-standard levels are forwarded rather than silently dropped [[target/app/core/logging.py::InterceptHandler]]. It then walks the call stack upward from `logging.currentframe()`, starting at depth `2` and incrementing while the current frame still belongs to the standard `logging` module itself, so that Loguru correctly attributes the log entry to the true originating call site rather than to the intermediary machinery [[target/app/core/logging.py::InterceptHandler]]. Finally, it dispatches to Loguru via `logger.opt(depth=depth, exception=record.exc_info).log(level, record.getMessage())`, forwarding both the computed depth and any exception information carried by the original record [[target/app/core/logging.py::InterceptHandler]]. The method is marked `# pragma: no cover` because it operates at the boundary of the logging infrastructure and is not exercised by the test suite [[target/app/core/logging.py::InterceptHandler]].

## InterceptHandler

[`InterceptHandler`](target/app/core/logging.py::InterceptHandler) is a standard Python logging handler whose sole responsibility is to act as a translation layer between the built-in `logging` module and Loguru, allowing the rest of the application to use the familiar `logging` API while Loguru handles the actual output [[target/app/core/logging.py::InterceptHandler]]. It is not a Pydantic model [[target/app/core/logging.py::InterceptHandler]]. It inherits directly from `logging.Handler`, which is the standard library base class for all log record handlers, and adds no new fields of its own [[target/app/core/logging.py::InterceptHandler]].

The class exposes a single method, [`emit`](target/app/core/logging.py::InterceptHandler::emit), which is the only behaviour it contributes beyond what it inherits from `logging.Handler` [[target/app/core/logging.py::InterceptHandler::emit]]. `emit` accepts a `logging.LogRecord` instance and always returns `None` [[target/app/core/logging.py::InterceptHandler::emit]]. When invoked, it first resolves the record's level name to a Loguru-native level; if Loguru does not recognise the name and raises a `ValueError`, it falls back to the raw numeric level as a string, ensuring that non-standard levels are forwarded rather than dropped [[target/app/core/logging.py::InterceptHandler::emit]]. It then walks the call stack from `logging.currentframe()` at an initial depth of `2`, incrementing while the active frame belongs to the standard `logging` module file, so that Loguru can attribute the log entry to the true originating call site rather than to the intermediary logging machinery [[target/app/core/logging.py::InterceptHandler::emit]]. Finally, it calls `logger.opt(depth=depth, exception=record.exc_info).log(level, record.getMessage())`, passing the computed depth and any exception information from the original record [[target/app/core/logging.py::InterceptHandler::emit]]. The method is marked `# pragma: no cover` because it operates at the boundary of the logging infrastructure and is not exercised by the test suite [[target/app/core/logging.py::InterceptHandler::emit]].

### emit

The [`emit`](target/app/core/logging.py::InterceptHandler::emit) method is the core bridge that forwards standard Python `logging` records into Loguru, allowing the rest of the application to use Python's built-in logging API while Loguru handles the actual output [[target/app/core/logging.py::InterceptHandler::emit]]. It accepts a single argument, `record`, which is a standard `logging.LogRecord` instance, and it always returns `None` [[target/app/core/logging.py::InterceptHandler::emit]].

The method first attempts to resolve the record's level name to a Loguru-native level by calling `logger.level(record.levelname).name`; if Loguru does not recognise the level name and raises a `ValueError`, it falls back to the raw numeric level converted to a string via `str(record.levelno)` [[target/app/core/logging.py::InterceptHandler::emit]]. This ensures that non-standard or custom logging levels are still forwarded rather than dropped [[target/app/core/logging.py::InterceptHandler::emit]].

Next, `emit` walks the call stack using `logging.currentframe()`, starting at depth `2` and incrementing while the current frame's filename matches the standard `logging` module file [[target/app/core/logging.py::InterceptHandler::emit]]. This loop locates the true call site that originally triggered the log record, bypassing the intermediary logging machinery, and `cast` is used to satisfy the type checker when accessing each frame's parent via `f_back` [[target/app/core/logging.py::InterceptHandler::emit]].

Finally, it calls `logger.opt(depth=depth, exception=record.exc_info).log(level, record.getMessage())`, passing the computed stack depth so Loguru attributes the log entry to the correct source location, and forwarding any exception information from the original record [[target/app/core/logging.py::InterceptHandler::emit]]. This method is marked `# pragma: no cover` because it operates at the boundary of the logging infrastructure and is not exercised by the test suite [[target/app/core/logging.py::InterceptHandler::emit]]. It belongs to the [`InterceptHandler`](target/app/core/logging.py::InterceptHandler) class, whose sole purpose is to act as this translation layer between the standard library and Loguru [[target/app/core/logging.py::InterceptHandler]].
