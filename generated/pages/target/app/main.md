# main

This module serves as the application entry point for the FastAPI service, responsible for assembling and exposing the fully configured application instance [[target/app/main.py]]. It defines a single factory function, `get_application`, and immediately invokes it at module level to produce the `app` object that ASGI servers consume [[target/app/main.py]].

The `get_application` function begins by retrieving application settings via `get_app_settings` and configuring logging through those settings [[target/app/main.py::get_application]]. It then constructs a `FastAPI` instance using keyword arguments sourced directly from the settings object [[target/app/main.py::get_application]]. `CORSMiddleware` is attached to the application to permit all methods and headers from the configured allowed hosts, with credentials enabled [[target/app/main.py::get_application]]. Lifecycle management is wired in by registering startup and shutdown handlers produced by `create_start_app_handler` and `create_stop_app_handler` respectively [[target/app/main.py::get_application]]. Application-level error handling is established by mapping `HTTPException` to `http_error_handler` and `RequestValidationError` to `http422_error_handler` [[target/app/main.py::get_application]]. Finally, the API router is mounted under the URL prefix defined in settings, and the fully configured `FastAPI` instance is returned to the call site [[target/app/main.py::get_application]].
