# jwt

This module is the application's JWT service layer, responsible for creating and validating signed access tokens [[target/app/services/jwt.py]]. It defines three module-level constants — `JWT_SUBJECT`, `ALGORITHM`, and `ACCESS_TOKEN_EXPIRE_MINUTES` — that fix the token type, signing algorithm, and lifetime (one week) for the entire service [[target/app/services/jwt.py]].

The lowest-level building block is `create_jwt_token`, a keyword-only function that accepts an arbitrary claims dictionary, a secret key, and an expiry delta, then merges in the standard `exp` and `sub` claims before calling `jwt.encode` and returning the resulting signed string [[target/app/services/jwt.py::create_jwt_token]]. It copies the incoming dictionary before modifying it, so the caller's original payload is never mutated [[target/app/services/jwt.py::create_jwt_token]]. The expiry timestamp is computed as an absolute UTC datetime by adding the supplied `expires_delta` to the current time, and the subject is always the module-level constant `JWT_SUBJECT` [[target/app/services/jwt.py::create_jwt_token]].

Built directly on top of that primitive is `create_access_token_for_user`, which is the entry point the rest of the application uses [[target/app/services/jwt.py::create_access_token_for_user]]. It accepts a `User` domain object and a secret key, serialises the user's username into a `JWTUser` payload, and delegates to `create_jwt_token` with an expiry delta derived from `ACCESS_TOKEN_EXPIRE_MINUTES`, returning whatever that call produces without further transformation [[target/app/services/jwt.py::create_access_token_for_user]].

The third function, `get_username_from_token`, is the inverse operation: given a raw JWT string and the signing secret, it decodes the token, validates the claims against the `JWTUser` schema, and returns the embedded username as a plain string [[target/app/services/jwt.py::get_username_from_token]]. Any cryptographic failure — an expired token, a tampered signature, or a mismatched key — is caught as a `PyJWTError` and re-raised as a `ValueError` with the message `"unable to decode JWT token"`, while a payload that decodes successfully but does not satisfy the `JWTUser` schema raises a `ValueError` with the message `"malformed payload in token"` instead [[target/app/services/jwt.py::get_username_from_token]]. Callers therefore have a single, uniform error type to handle on the failure path and a bare username string on success [[target/app/services/jwt.py::get_username_from_token]].

## create_access_token_for_user

`create_access_token_for_user` is a function that generates a signed JWT access token for a given user [[target/app/services/jwt.py::create_access_token_for_user]]. It accepts two parameters: a `User` object and a `secret_key` string, and returns a `str` containing the encoded token [[target/app/services/jwt.py::create_access_token_for_user]].

Internally, it constructs a `JWTUser` payload from the user's username, serialises it to a dictionary, and passes that along with the secret key and a computed expiry delta to `create_jwt_token` [[target/app/services/jwt.py::create_access_token_for_user]]. The expiry window is determined by the module-level constant `ACCESS_TOKEN_EXPIRE_MINUTES`, which is supplied to `timedelta` to produce the `expires_delta` argument [[target/app/services/jwt.py::create_access_token_for_user]]. The function returns whatever `create_jwt_token` produces directly, with no additional transformation [[target/app/services/jwt.py::create_access_token_for_user]].

## create_jwt_token

`create_jwt_token` is a keyword-only function that builds and returns a signed JWT string [[target/app/services/jwt.py::create_jwt_token]]. It accepts three inputs: `jwt_content`, a `Dict[str, str]` holding the claims to embed; `secret_key`, the string used to sign the token; and `expires_delta`, a `timedelta` controlling how far in the future the token expires [[target/app/services/jwt.py::create_jwt_token]].

The function begins by copying `jwt_content` so that the original dictionary is not mutated [[target/app/services/jwt.py::create_jwt_token]]. It then computes an absolute expiry timestamp by adding `expires_delta` to the current UTC time [[target/app/services/jwt.py::create_jwt_token]]. A `JWTMeta` object is constructed with that expiry and a module-level constant `JWT_SUBJECT`, and its dictionary representation is merged into the working copy, adding the standard `exp` and `sub` claims [[target/app/services/jwt.py::create_jwt_token]]. Finally, `jwt.encode` is called with the assembled payload, `secret_key`, and a module-level `ALGORITHM` constant, and its result — a signed JWT string — is returned directly to the caller [[target/app/services/jwt.py::create_jwt_token]].

The function carries no route-registration or authorization decorators, raises no explicit exceptions of its own, and its return type is `str` [[target/app/services/jwt.py::create_jwt_token]].

## get_username_from_token

`get_username_from_token` accepts a JWT string and a secret key, then attempts to decode the token and extract the authenticated username from its payload [[target/app/services/jwt.py::get_username_from_token]]. It calls `jwt.decode` with the provided `token` and `secret_key`, passing the expected algorithm constant `ALGORITHM`, and constructs a `JWTUser` from the resulting claims in order to access its `username` field, which is then returned as a plain `str` [[target/app/services/jwt.py::get_username_from_token]]. If the JWT library raises a `PyJWTError` — for example because the token is expired, tampered with, or signed with a different key — the function catches it and re-raises a `ValueError` with the message `"unable to decode JWT token"` [[target/app/services/jwt.py::get_username_from_token]]. If the decoded payload is structurally valid JSON but does not satisfy the `JWTUser` schema, a `ValidationError` is caught instead and a second `ValueError` with the message `"malformed payload in token"` is raised in its place [[target/app/services/jwt.py::get_username_from_token]]. Callers should therefore expect a `ValueError` on any failure path and a bare `str` username on the success path [[target/app/services/jwt.py::get_username_from_token]].

> **Raises:** ValueError
