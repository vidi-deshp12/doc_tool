# api

This module serves as the top-level API router that assembles all feature-specific sub-routers into a single unified router for the application [[target/app/api/routes/api.py]]. It creates a root `APIRouter` instance and registers six sub-routers onto it, each bound to a specific URL prefix and tagged for grouping in the generated API schema [[target/app/api/routes/api.py]]. The authentication routes are mounted under `/users`, user profile management routes under `/user`, and profiles under `/profiles` [[target/app/api/routes/api.py]]. Article routes are included without an additional prefix, while comment routes are nested under `/articles/{slug}/comments` to reflect their relationship to a specific article identified by its slug [[target/app/api/routes/api.py]]. Tag routes are mounted under `/tags`, completing the full surface of the API [[target/app/api/routes/api.py]]. The articles sub-router is sourced from a nested `api` module within the `articles` package, while all other sub-routers are imported directly from their respective sibling modules [[target/app/api/routes/api.py]].
