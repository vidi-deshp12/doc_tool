# api

This module serves as the top-level API router that assembles all feature-specific sub-routers into a single `APIRouter` instance for the application [[target/app/api/routes/api.py]]. A root `router` object is created and then extended by mounting six sub-routers, each scoped to its own URL prefix and tag: authentication routes are mounted under `/users`, user routes under `/user`, profile routes under `/profiles`, article routes without an additional prefix, comment routes under `/articles/{slug}/comments`, and tag routes under `/tags` [[target/app/api/routes/api.py]]. By centralising all `include_router` calls here, this file acts as the single wiring point that connects every domain area of the API into one coherent router, which the application can register in one step [[target/app/api/routes/api.py]].
