# api

This module serves as the top-level API router that assembles all feature-specific sub-routers into a single FastAPI `APIRouter` instance [[target/app/api/routes/api.py]]. It imports route handlers for authentication, users, profiles, articles, comments, and tags from their respective sub-modules, then registers each one on the central `router` object using `include_router` [[target/app/api/routes/api.py]]. Each sub-router is mounted under a dedicated URL prefix — `/users` for authentication, `/user` for the current user, `/profiles` for profiles, `/tags` for tags, and `/articles/{slug}/comments` for comments — while the articles router is included without an additional prefix [[target/app/api/routes/api.py]]. Grouping tags are also assigned per sub-router (for example `"authentication"`, `"comments"`, `"articles"`) so that the auto-generated OpenAPI documentation organises endpoints by feature [[target/app/api/routes/api.py]]. The resulting `router` object is the single export that the application mounts to wire all API routes together [[target/app/api/routes/api.py]].
