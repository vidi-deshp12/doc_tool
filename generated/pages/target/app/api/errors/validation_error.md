# validation_error

This module configures FastAPI's validation error handling by customising the OpenAPI response schema and providing a dedicated error handler [[target/app/api/errors/validation_error.py]]. At module level, it patches `validation_error_response_definition["properties"]` to replace the default schema with a single `"errors"` array whose items reference the standard `ValidationError` OpenAPI component, ensuring the generated API documentation accurately reflects the error envelope shape [[target/app/api/errors/validation_error.py]]. The central function, `http422_error_handler`, accepts a `Request` (which it ignores) alongside either a `RequestValidationError` or a `ValidationError`, calls `exc.errors()` to extract the structured validation details, and returns them wrapped in a `{"errors": ...}` envelope as a `JSONResponse` with HTTP status 422 Unprocessable Entity [[target/app/api/errors/validation_error.py::http422_error_handler]]. Together, the module-level schema patch and the handler function ensure that both the runtime error response and the static OpenAPI documentation agree on the same `{"errors": [...]}` structure [[target/app/api/errors/validation_error.py]] [[target/app/api/errors/validation_error.py::http422_error_handler]].

## http422_error_handler

Accepts a `Request` (ignored) and either a `RequestValidationError` or `ValidationError` exception, then calls `exc.errors()` to extract the validation error details and wraps them in a `{"errors": ...}` envelope returned as a `JSONResponse` with HTTP status 422 Unprocessable Entity [[target/app/api/errors/validation_error.py::http422_error_handler]].
