# strings

This module is a central registry of human-readable API error and status message strings used throughout the application [[target/app/resources/strings.py]]. It defines a flat collection of module-level string constants, each corresponding to a specific error or boundary condition that the API may need to communicate to a client [[target/app/resources/strings.py]].

The constants cover several distinct concern areas. User-related errors include messages for a missing user, duplicate username or email at registration, and incorrect login credentials [[target/app/resources/strings.py]]. Article-related errors cover cases where an article does not exist, already exists, has already been favorited, is not currently favorited, or where the requesting user is not its author [[target/app/resources/strings.py]]. Follow/subscription errors describe attempts to follow or unfollow oneself, following a user that is already followed, and unfollowing a user that is not currently followed [[target/app/resources/strings.py]]. Authentication errors handle an unsupported authorization prefix, a payload that cannot be validated, and a general authentication-required condition [[target/app/resources/strings.py]]. Finally, a comment error constant covers the case where a requested comment does not exist [[target/app/resources/strings.py]].

By centralising all these literals in one place, the module ensures that any code path raising or returning one of these messages can import it by name rather than repeating the raw string, keeping error text consistent and easy to update in a single location [[target/app/resources/strings.py]].
