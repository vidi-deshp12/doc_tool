# tags

This module defines the database repository layer for tags in the application [[target/app/db/repositories/tags.py]]. Its sole export is `TagsRepository`, a class that centralises all tag-related database interactions and inherits from `BaseRepository`, which provides connection management and shared repository infrastructure [[target/app/db/repositories/tags.py::TagsRepository]].

The class exposes exactly two asynchronous methods that together form a minimal read/write interface, keeping query details hidden from callers [[target/app/db/repositories/tags.py::TagsRepository]]. On the read side, `get_all_tags` takes no arguments beyond `self`, delegates to `queries.get_all_tags` through `self.connection`, and returns a flat `List[str]` by extracting the first element of every row the query produces [[target/app/db/repositories/tags.py::TagsRepository]]. On the write side, `create_tags_that_dont_exist` accepts a single keyword-only argument `tags` typed as `Sequence[str]`, converts each string into a `{"tag": tag}` dictionary, and forwards that list alongside `self.connection` to `queries.create_new_tags`, returning `None` [[target/app/db/repositories/tags.py::TagsRepository]]. Neither method carries decorators nor raises exceptions of its own [[target/app/db/repositories/tags.py::TagsRepository]].

## TagsRepository

`TagsRepository` is a class defined in [`target/app/db/repositories/tags.py`](target/app/db/repositories/tags.py) that handles all database interactions related to tags [[target/app/db/repositories/tags.py::TagsRepository]]. It inherits from `BaseRepository`, acquiring that class's connection management and any shared repository infrastructure [[target/app/db/repositories/base.py::BaseRepository]]. It is not a Pydantic model [[target/app/db/repositories/tags.py::TagsRepository]].

The read-side method, `get_all_tags`, takes no arguments beyond `self`, delegates to `queries.get_all_tags` via `self.connection`, and returns a flat `List[str]` built by extracting the first element from each returned row [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]]. The write-side method, `create_tags_that_dont_exist`, accepts a single keyword-only argument `tags` typed as `Sequence[str]`, transforms each string into a `{"tag": tag}` dictionary, and passes the resulting list alongside `self.connection` to `queries.create_new_tags`, returning `None` [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]]. Neither method carries decorators nor raises exceptions of its own [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]] [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]]. Together the two methods form a minimal read/write interface for tag persistence, keeping all query and connection details hidden from callers [[target/app/db/repositories/tags.py::TagsRepository]].

### create_tags_that_dont_exist

`create_tags_that_dont_exist` is an asynchronous method on the `TagsRepository` class that accepts a sequence of tag strings and persists any new ones to the database, returning nothing [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]]. It takes a single keyword-only argument, `tags`, typed as `Sequence[str]`, and has a return type of `None` [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]]. Internally, it delegates all database work to `queries.create_new_tags`, passing the repository's active connection alongside a list of dictionaries built by transforming each string in `tags` into the form `{"tag": tag}` [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]]. The method carries no decorators and raises no exceptions of its own; it simply awaits the query call and returns [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]]. Its role within `TagsRepository` is to act as the write-side entry point for tag creation, ensuring that the caller can supply a batch of tag names without needing to know anything about the underlying query or connection management [[target/app/db/repositories/tags.py::TagsRepository]] [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]].

### get_all_tags

`get_all_tags` is an asynchronous method defined on the `TagsRepository` class that retrieves every tag stored in the database and returns them as a flat list of strings [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]]. It takes no arguments beyond the implicit `self` and is declared with `async`, meaning it must be awaited by its callers [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]].

Internally, it delegates the database query to `queries.get_all_tags`, passing `self.connection` as the connection argument, and awaits the result [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]]. The query returns rows, each of which is an indexable sequence; the method extracts the first element of every row via a list comprehension, yielding a `List[str]` of tag values [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]]. No exceptions are explicitly raised, and no decorators are applied to this method [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]].
