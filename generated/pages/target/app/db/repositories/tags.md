# tags

This module defines the tag-related database access layer for the application, containing a single repository class that handles all tag persistence concerns [[target/app/db/repositories/tags.py]].

`TagsRepository` inherits from `BaseRepository` and is responsible for managing tag records in the database [[target/app/db/repositories/tags.py::TagsRepository]]. It declares no fields of its own, relying entirely on the connection object provided by its base class, which it passes through to every query call [[target/app/db/repositories/tags.py::TagsRepository]]. The class exposes two asynchronous methods that together cover the read and write operations needed for tags [[target/app/db/repositories/tags.py::TagsRepository]]. The first, `get_all_tags`, retrieves every stored tag from the database and returns them as a flat `List[str]` by extracting the first column from each result row [[target/app/db/repositories/tags.py::TagsRepository]]. The second, `create_tags_that_dont_exist`, accepts a keyword-only `tags` argument — a sequence of strings — and persists any tags not yet present in the database by delegating to the shared `queries` object with a list of `{"tag": tag}` dictionaries, one per input entry, returning `None` on completion [[target/app/db/repositories/tags.py::TagsRepository]]. Both methods immediately await their respective query calls, participating in the async I/O model used throughout the repository layer [[target/app/db/repositories/tags.py::TagsRepository]].

## TagsRepository

`TagsRepository` is a database repository class responsible for managing tag records, and it inherits directly from `BaseRepository` [[target/app/db/repositories/tags.py::TagsRepository]] [[target/app/db/repositories/base.py::BaseRepository]]. It is not a Pydantic model; it is a plain Python class that extends its base class without declaring any fields of its own [[target/app/db/repositories/tags.py::TagsRepository]]. The connection object it relies on is inherited from `BaseRepository` and is passed through to every query call [[target/app/db/repositories/base.py::BaseRepository]].

The class exposes two asynchronous methods [[target/app/db/repositories/tags.py::TagsRepository]]. The first, `get_all_tags`, queries the database for every stored tag and returns a flat `List[str]` by extracting the first column from each result row [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]]. The second, `create_tags_that_dont_exist`, accepts a keyword-only `tags` argument — a sequence of strings — and persists any tags not yet present in the database by delegating to `queries.create_new_tags` with a list of `{"tag": tag}` dictionaries, one per input entry, returning `None` on completion [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]]. Both methods participate in the async I/O model used throughout the repository layer by immediately awaiting their respective query calls [[target/app/db/repositories/tags.py::TagsRepository]].

### create_tags_that_dont_exist

`create_tags_that_dont_exist` is an asynchronous method on the [`TagsRepository`](target/app/db/repositories/tags.py::TagsRepository) class that accepts a keyword-only argument `tags`, a sequence of strings, and returns `None` [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]]. Its sole responsibility is to persist any tags that do not yet exist in the database, delegating the actual work to `queries.create_new_tags` by passing the repository's active connection alongside a list of dictionaries shaped as `{"tag": tag}`, one per entry in the input sequence [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]]. Because it is declared `async` and immediately `await`s the query call, it participates in the async I/O model used throughout the [`TagsRepository`](target/app/db/repositories/tags.py::TagsRepository) [[target/app/db/repositories/tags.py::TagsRepository]]. No exceptions are explicitly raised, no decorators are applied, and the method produces no return value beyond confirming the operation completed [[target/app/db/repositories/tags.py::TagsRepository::create_tags_that_dont_exist]].

### get_all_tags

`get_all_tags` is an asynchronous method on the [`TagsRepository`](target/app/db/repositories/tags.py::TagsRepository) class that retrieves all tags stored in the database [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]]. It takes no arguments beyond `self` and delegates the actual database query to `queries.get_all_tags`, passing the repository's connection object [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]]. The raw result is a sequence of row tuples, and the method extracts the first column from each row, returning a flat `List[str]` of tag names to the caller [[target/app/db/repositories/tags.py::TagsRepository::get_all_tags]].
